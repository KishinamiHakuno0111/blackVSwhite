# 黑白棋桌面界面设计

平台：Python / Tkinter，Windows 桌面。用途：休闲与策略棋盘对战。

应用 ui-ux-pro-max 的样式检索结果 `minimalism-and-swiss-style`：明确网格、留白、少量颜色、可辨认状态。初次完整设计检索给出了展示型网站和 3D 方案，与本桌面棋盘产品不合，未直接套用；保留适合棋盘的绿色方向，采用后续明确匹配的极简样式。

- 主背景：暖灰白 `#F3F1EA`，卡片 `#FCFBF7`。
- 文字：深绿 `#203C32`，次级说明 `#56685F`。
- 棋盘：绿色 `#205747` / `#245D4D`，网格 `#3D7460`。
- 棋子：黑 `#15221D`、米白 `#F8F5E9`，点标记上一手。
- 提示：金色 `#F0D48D`，建议落点同时标注“建议”，不只依赖颜色。
- 字体：系统 Microsoft YaHei UI，无网络字体；标题 26pt，正文 10–12pt，辅助文本 9pt。
- 结构：上方标题与文件操作；左侧比分和自适应棋盘；右侧对局设置、AI 信息及棋谱；底部当前回合状态。
- 操作：鼠标、方向键/Enter、Tab 与键盘快捷键；可操作的合法格悬停反馈；思考状态与禁用状态明确。
- 搜索运行于独立进程；新局/悔棋/关闭取消工作，保持界面响应。
- 不自动播放装饰动画。仅显示 AI 计算进度活动条。
- 默认窗口 1180×850，最小 1000×780；两个尺寸都检查截图与关键控件布局。

当前只提供这一种主题；Tk Canvas 屏幕阅读器支持没有做认证。不把移动端安全区或网页 CSS 技术要求直接套用到桌面窗口。

## 8×8 分支

沿用现有配色、窗口尺寸和控件布局，棋盘改为 A1–H8 的 64 格。格子随窗口缩放，键盘焦点限制在 8 行 8 列内；右边界、下边界及棋盘外点击不可落子。标题、规则和存档默认名称明确标注 8×8。
