# 黑白棋 v1.0.0

首个 Python 桌面开源版本，统一使用 10×10 棋盘，整合旧 superAI / superAI2.0 的策略思路并修复基础规则和搜索缺陷。

## 下载和运行

- **BlackWhiteChess.exe**：Windows x64 单文件程序，双击运行，无需安装 Python。
- **BlackWhiteChess-Windows-x64.zip**：同一程序，附使用说明、MIT 及第三方许可文本。
- **SHA256SUMS.txt**：上面两个文件的 SHA-256 校验值。

目标为 Windows 10/11 x64，已在 Windows 10 x64 验证。程序离线运行，无需管理员权限。
启动时会解包内置运行库，请稍等片刻。其他系统可下载源码自行运行；未在其他电脑或系统验证。

## 功能

- 鼠标和键盘落子；人机、双人和 AI 演示模式。
- 三档 AI，支持执黑/执白、推荐落点、悔棋、保存和载入。
- 完整八方向翻转、强制跳过、双方无棋可下时的胜负与平局判定。
- 迭代加深、Alpha-Beta、置换表、阶段性评价、稳定子、空区奇偶性、有限模拟及残局搜索。
- AI 在独立进程计算，支持取消，界面保持响应。

## 验证

32 项规则、搜索和桌面交互测试通过。打包 exe 在移除 Python 环境路径、含中文和空格的独立目录下，
通过真实 AI 子进程、鼠标落子、推荐落点、悔棋、存档恢复、AI 先手及完整对局结算检查。
这不是在没有 Python 的全新虚拟机中的测试。棋力没有做全局最优或竞赛排名承诺。

项目源码采用 MIT 许可证，内置第三方组件保留各自许可证。
