# 8×8 分支说明

分支：`feature/8x8-board`。基于 main 的 `510f64a`，保留完整桌面功能，改用 8×8 棋盘。
main 和既有 `v1.0.0` Release 仍是 10×10 版。

## 规则和策略

- 棋盘为 64 格，坐标 A1–H8。初始黑棋 E4、D5，白棋 D4、E5；黑先行，初始合法落点 D3、C4、F5、E6。
- 方向步长、边界掩码、角位、中心位置、空位统计和棋谱最大长度均适配 8×8。
- AI 保留 Alpha-Beta、迭代加深、置换表、行动力、稳定子、空区奇偶性、有限随机模拟和残局求解。
- 位置权重重排为对称的 8×8 表，角邻域改为 A1/H1/A8/H8 周围的 C/X 格。
- 阶段评价按空位占 64 格的比例划分：39–60 空位为早期，13–38 为中期，0–12 为后期。
- 快速/均衡/深入仍分别用约 0.3/1/3 秒预算；8/10/12 空位以内分别尝试完整残局搜索。
- 存档标记 `size: 8`，最多 60 步。10×10 存档不能载入；载入失败保留当前对局。

## 界面和打包

棋盘坐标、鼠标命中、方向键边界、标题和规则均更新为 8×8。保留人机、双人、AI 演示、
选择执黑/执白、提示、悔棋、暂停以及保存载入功能。

```powershell
python main.py
& .\tools\build_windows.ps1
python tools\verify_windows.py
```

独立产物为 `dist/BlackWhiteChess-8x8.exe` 和 `dist/BlackWhiteChess-8x8-Windows-x64.zip`。
构建不会覆盖 10×10 的 exe 或压缩包。源码上传到新分支，构建产物保留在本地 `dist/`。

## 验证

- **36 项测试通过**：30 局逐步对照独立数组规则；5 个六空位残局对照独立穷举；
  真实 Tk 点击和键盘操作、强制跳过、完整对局、实际 AI 子进程、存档、取消和悔棋。
- 新增 8×8 坐标上限、拒绝 10×10 存档、拒绝载入后保留当前对局、键盘四边界和 AI 八种旋转/镜像一致性检查。
- 六局配对开局、黑白换色，对阵“当步翻子最多”基线，结果 **6 胜 0 平 0 负**。
  预算 0.08 秒/步，是小样本回归检查；结果受机器性能和系统负载影响，不是竞赛排名。
  原始记录见 [benchmark-8x8.json](validation/benchmark-8x8.json)。
- 在 1180×850、1000×780 两种窗口尺寸检查实际截图；棋盘、比分、记录、控件和状态栏完整可见。
- 打包 exe 在独立中文/空格目录、移除 Python 环境路径的条件下通过 8×8 初始化、鼠标落子、
  AI 回应、提示、悔棋、保存恢复、AI 先手与完整对局结算。记录见 [packaging-8x8.json](validation/packaging-8x8.json)。
  本机系统为 Windows 10 x64，尚未在其他电脑或全新无 Python 系统验证。

旧 C/C++ 审计和初版 10×10 迁移记录分别保留在 `PROJECT_STATUS.md`、`MIGRATION_NOTES.md`，属于历史资料。
